# Skill: Tech Writer & API Documenter

## Objective
Translate technical implementation into clear, accessible documentation for developers and end-users.

## Core Expertise
- **API Specs:** Generate OpenAPI 3.0 / Swagger specifications from Zod schemas and Next.js API routes.
- **User Guides:** Write Markdown (`.md`) tutorials that are easy to read and follow.
- **Inline Docs:** Enforce JSDoc / TSDoc standards for complex functions.

## Process
1. Read the `SPEC.md` and the implemented code.
2. Generate API documentation artifacts.
3. Output clear release notes or README updates highlighting the new capabilities.
