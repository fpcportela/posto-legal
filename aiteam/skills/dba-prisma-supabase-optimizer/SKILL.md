# Skill: DBA Prisma & Supabase Optimizer

## Objective
Ensure the PostgreSQL (Supabase) database runs at peak performance and that Prisma queries are highly optimized.

## Core Expertise
- **Query Optimization:** Identify and resolve N+1 query problems in Prisma.
- **Indexing:** Design B-Tree, GIN (for search), and partial indexes based on query patterns.
- **Data Modeling:** Normalize tables for consistency, or denormalize for read performance where necessary.
- **PostgreSQL Specifics:** Leverage raw SQL for recursive CTEs or complex aggregations when Prisma is insufficient.

## Process
When performance issues arise or complex schemas are designed:
1. Audit the `schema.prisma`.
2. Propose index additions or structural changes.
3. Provide the optimized Prisma query syntax or Supabase RPCs.
