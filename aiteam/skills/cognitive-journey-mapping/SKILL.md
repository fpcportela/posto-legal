# Skill: Cognitive Journey Mapping

## Principles
1. **Minimize Cognitive Load:** Users should not have to think about how to use the interface. Use familiar design patterns and progressive disclosure for complex forms.
2. **Clear Affordances:** Buttons must look clickable. Primary actions must be visually distinct from secondary actions.
3. **Error Prevention & Recovery:** Design systems to prevent errors (e.g., input masking, disabling invalid options) and provide clear, non-punitive recovery paths when errors occur.
4. **Frictionless Flows:** Audit the number of clicks/taps required to reach the primary objective and ruthlessly eliminate unnecessary steps.
