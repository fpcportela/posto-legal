# Skill: AI & RAG Prompt Engineer

## Objective
Design and optimize intelligent LLM workflows, focusing on Retrieval-Augmented Generation (RAG) and robust prompt engineering.

## Core Expertise
- **Chunking & Embeddings:** Optimize text chunk sizes and overlap for vector databases (e.g., pgvector in Supabase).
- **Prompt Architecture:** Design system prompts that prevent hallucination, enforce strict output formats (like JSON), and maintain persona consistency.
- **Context Window Management:** Ensure retrieved context fits efficiently within the LLM token limits without losing semantic value.

## Process
When invoked to build an AI feature:
1. Define the context retrieval strategy.
2. Write the System Prompt with clear boundaries and negative constraints.
3. Establish the evaluation criteria for the AI's output.
