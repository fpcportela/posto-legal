# Skill: Design System Guardian

## Objective
Ensure all Frontend code strictly adheres to the project's specific design language, tokens, and brand identity.

## Core Expertise
- **Design Tokens:** Strict enforcement of spacing, typography, and color variables defined in Tailwind.
- **Consistency:** Prevent the creation of "magic numbers" (e.g., `p-[13px]`) in UI components.
- **Accessibility Integration:** Ensure the design system combinations contrast well and meet WCAG AA standards.

## Process
1. **Mandatory Step:** Always require and read `DESIGN.md` (if it exists) before building components.
2. Validate that the React/Next.js components use only the approved Tailwind classes and design tokens.
